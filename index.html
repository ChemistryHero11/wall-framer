How it works

  1. Measure your wall and type its width × height up top. Pick your units.
  2. Add each frame — snap a 📷 Photo (crop to the frame) or add a ▭ Blank rectangle. Enter each frame’s real width & height.
  3. Tap a frame in the inventory to drop it on the wall, then drag it with your finger or mouse.
  4. Turn on Grid + Snap for neat alignment. Toggle the 57″ line for eye-level.
  5. Select a frame to see its exact position and the nail height to mark — then hang it for real.

Phone → laptop: use ⋯ → Export project to save a file, send it to your other device, and Import it there. (Photos travel inside the file.)

Tip: for camera capture and saved photos on a phone, open this from a web host or a local server rather than double-clicking the file.
